Notch

A temporary shelf for the files you are working with. Drop them at the top of the screen, share them, send them to another computer.

Download

Linux · Windows

Linux

Debian, Ubuntu, Kubuntu · 64-bit · tested on KDE Plasma (Wayland)

Download .deb
  1. Download the package.
  2. Install it; apt brings everything it needs:
sudo apt install ./notch_VERSION_amd64.deb
  1. Start Notch from the application menu.
Optional and removal 
sudo apt install tesseract-ocr   # OCR tool
sudo apt remove notch            # remove (your shelf is kept)
Other distributions: build from source 
git clone https://github.com/Kepin17/olyzano-notch
cd olyzano-notch
sudo apt install cmake ninja-build g++ qt6-base-dev \
  qt6-declarative-dev liblayershellqtinterface-dev
cmake -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build && ./build/notch

Windows

Windows 10 and 11 · 64-bit

Download installer Portable .zip
  1. Run the installer. It installs for your user, no administrator prompt.
  2. Windows may say “Windows protected your PC” because the build is not code-signed: click More info → Run anyway.
  3. Start Notch from the Start menu.
Good to know
  • The portable zip needs no install: extract it and run notch.exe.
  • Sharing over WiFi or Nearby: allow Notch through the firewall on private networks.
  • PDF and OCR tools need Poppler, Ghostscript and Tesseract on your PATH.
  • Remove: Settings → Apps → Notch → Uninstall.
The shelfDrop files, folders, images, links and notes; preview and organize them.
Share via QROver your WiFi or your own encrypted server, with PIN or password.
NearbySend to another computer running Notch, after matching a 4-digit code.
ToolsMerge and split PDFs, convert images, OCR, zip.
