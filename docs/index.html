A temporary shelf for the files you are working with.

Move the pointer to the top edge of your screen and Olyzano Notch slides out. Drop files on it, take them back when you need them, and send them to a phone or another computer. Originals are never touched, and the shelf cleans itself up.

Download

Free and open source. Each release is built automatically from the repository.

Linux

64-bit, Qt 6.5 or newer. Debian 13, Ubuntu 25.04 or newer, KDE neon. Made for KDE Plasma.

Debian package (.deb)
  1. Download the package.
  2. Install it. apt brings in everything it needs.
  3. Start Olyzano Notch from the application menu.
sudo apt install ./notch_VERSION_amd64.deb
Remove, or build from source 
sudo apt remove notch
git clone https://github.com/Kepin17/olyzano-notch
cd olyzano-notch
sudo apt install cmake ninja-build g++ qt6-base-dev \
  qt6-declarative-dev liblayershellqtinterface-dev
cmake -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build && ./build/notch

Windows

Windows 10 or 11, 64-bit.

Installer (.exe) Portable (.zip)
  1. Run the installer. It installs for your user and needs no administrator rights.
  2. The build is not code-signed yet, so Windows SmartScreen may warn you (the app is new to Microsoft, nothing was found in it). Choose More info, then Run anyway. To check the file, compare its SHA-256 with SHA256SUMS-windows.txt on the release page.
  3. Start Olyzano Notch from the Start menu.
Notes
  • The portable archive needs no install: extract it and run notch.exe.
  • Sharing over WiFi and Nearby: allow Olyzano Notch through the firewall on private networks.
  • PDF and OCR tools need Poppler, Ghostscript and Tesseract on your PATH.
  • Remove it in Settings, Apps, Olyzano Notch.

What it does

Small, local, and out of the way until you need it. These are the app's own screens, drawn the way it draws them.

A shelf for files in transit

Drop files, folders, images, links and text on the notch. Preview them, sort them into categories, drag them back out, and let old ones expire on their own.

New

An app launcher with search

Type a few letters, press Enter. Pin favourites, see recent apps, filter by group, and open it with the Windows key.

New

A glass status bar with Quick Settings

The app in front with its own menu, a tray, the clock with a calendar, and one card for Wi-Fi (with real signal bars, details and a password QR), Ethernet, Bluetooth, sound, microphone, brightness and power.

New

Tray and KDE Connect

Background apps sit on the bar, click to open, right-click for their menu. Your phone's battery is there too, with ping, find and a button for KDE Connect.

Share by QR code

Hand a file to a phone over your WiFi, or through a server you run, with a PIN or password and an expiry. A pill in the notch brings the session back.

Send to another computer

Nearby finds other Olyzano Notch computers on the network. Both screens show the same four digits; the receiver accepts.

Everyday tools

Merge and split PDFs, convert and resize images, extract text with OCR, make zip archives. Right on the shelf, from the file's menu.

Fourteen themes, Japanese and Korean colours included

Each in dark and light: Washi, Sakura, Matcha and Ai from Japan; Cheongja, Hanbok and Hanji from Korea; and the calm ones from before.

Private, with safety nets

Files stay on your computer. Undo, a 24-hour bin for removed files, locked categories encrypted on disk, and names that never overwrite anything.

Music, timer and colours

The song and its synced lyrics, a Pomodoro timer, and a screen colour picker that copies HEX, RGB or HSL, one page after another in the same notch.

New

A nudge when it is too much

Stretch reminders after long work, and a warning when Instagram, TikTok or Shorts has eaten too much of your hour. Gentle, never blocking.
