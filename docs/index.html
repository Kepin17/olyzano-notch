A temporary shelf for the files you are working with.

Move the pointer to the top edge of your screen and Notch slides out. Drop files on it, take them back when you need them, and send them to a phone or another computer. Originals are never touched, and the shelf cleans itself up.

Download

Free and open source. Each release is built automatically from the repository.

Linux

64-bit, Qt 6.5 or newer. Debian 13, Ubuntu 25.04 or newer, KDE neon. Made for KDE Plasma.

Debian package (.deb)
  1. Download the package.
  2. Install it. apt brings in everything it needs.
  3. Start Notch from the application menu.
sudo apt install ./notch_VERSION_amd64.deb
Remove, or build from source 
sudo apt remove notch
git clone https://github.com/Kepin17/olyzano-notch
cd olyzano-notch
sudo apt install cmake ninja-build g++ qt6-base-dev \
  qt6-declarative-dev liblayershellqtinterface-dev
cmake -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build && ./build/notch

Windows

Windows 10 or 11, 64-bit.

Installer (.exe) Portable (.zip)
  1. Run the installer. It installs for your user and needs no administrator rights.
  2. The build is not code-signed, so Windows may warn you. Choose More info, then Run anyway.
  3. Start Notch from the Start menu.
Notes
  • The portable archive needs no install: extract it and run notch.exe.
  • Sharing over WiFi and Nearby: allow Notch through the firewall on private networks.
  • PDF and OCR tools need Poppler, Ghostscript and Tesseract on your PATH.
  • Remove it in Settings, Apps, Notch.

What it does

Small, local, and out of the way until you need it.

A shelf for files in transitDrop files, folders, images, links and text. Preview them, sort them into categories, and let old ones expire.
Share by QR codeHand a file to a phone over your WiFi, or through a server you run, with a PIN or password and an expiry.
Send to another computerNearby finds other Notch computers on the network. Both screens show the same four digits; the receiver accepts.
Everyday toolsMerge and split PDFs, convert and resize images, extract text with OCR, make zip archives.
Private by designFiles stay on your computer. Server shares are encrypted before they leave it. Locked categories are encrypted on disk.
Safety netsUndo, a 24-hour bin for removed files, and names that never overwrite anything.
