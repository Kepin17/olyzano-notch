New App dock, live activities, Pomodoro and a stretch reminder

Your files, apps and focus, at the edges of your screen.

Notch slides out from the top of the screen with a shelf for the files you're working with, shows what's going on in a little live pill, and adds a dock at the bottom. For KDE Plasma and Windows.

Install

Pick your system. The buttons always point at the newest release.

Debian · Ubuntu · Kubuntu · KDE neon

64-bit, Qt 6.5 or newer. Made for KDE Plasma (Wayland or X11).

  1. Download the package ⬇ Download .deb 
    wget https://github.com/Kepin17/olyzano-notch/releases/latest/download/notch_VERSION_amd64.deb
  2. Install it apt brings everything it needs. 
    sudo apt install ./notch_VERSION_amd64.deb
  3. Start Notch from the application menu. Rest the mouse on the top-centre edge to open it; turn on Settings → General → Start at login to have it always.
Update or remove

Update: install the newer .deb the same way, then restart Notch. Your shelf and settings stay.

pkill notch; notch &          # restart after an update
sudo apt remove notch          # remove (your shelf is kept)
rm -r ~/.local/share/notch ~/.config/notch   # delete the shelf and settings too

What you get where

  • ✅KDE Plasma: everything: dock window focusing, blur, badges, KDE Connect, idle time on Wayland.
  • 🟡Other desktops: the shelf, timer and sharing work; the dock can start apps but not raise their windows.
  • 🧩Extras like OCR and KDE Connect are optional components.
Older Ubuntu (24.04 and before) ships Qt 6.4, which is too old. Use a newer release, KDE neon, or build from source with a newer Qt.

Windows 10 and 11

64-bit. Installs for your user, no administrator prompt.

  1. Download the installer
    ⬇ Installer (.exe) Portable .zip
  2. Run it. Windows may say "Windows protected your PC" because the build isn't code-signed: click More info → Run anyway. The portable zip needs no install: extract it and run notch.exe.
  3. Start Notch from the Start menu. Allow it through the firewall on private networks if you share over WiFi or use Nearby.

Good to know

  • 📄PDF tools and OCR need Poppler, Ghostscript and Tesseract: see optional components.
  • 📁Settings and files live in %LOCALAPPDATA%\notch.
  • 🗑️Remove: Settings → Apps → Notch → Uninstall.
  • ➖Linux-only: KDE Connect, phone alerts, privacy dots, locked categories, dock blur and badges.

How do I add a folder to PATH on Windows?

Start → type environment variables → Edit the environment variables for your account → select Path → Edit → New → paste the folder → OK. Then restart Notch.

Build from source

Needs Qt 6.5 or newer (Debian 13, Ubuntu 25.04+). The optional libraries are found automatically.

git clone https://github.com/Kepin17/olyzano-notch
cd olyzano-notch
# required
sudo apt install cmake ninja-build g++ libssl-dev qt6-base-dev qt6-base-private-dev qt6-declarative-dev
# optional
sudo apt install liblayershellqtinterface-dev   # Wayland: pin the notch and dock to the screen edges
sudo apt install libkf6windowsystem-dev         # blur behind the dock (KDE Plasma)
sudo apt install libkf6idletime-dev             # stretch reminder: idle time on Wayland
cmake -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build && ./build/notch
cd build && cpack                               # makes notch_<version>_amd64.deb

Windows builds need Qt 6.8 (MSVC 2022), CMake, Ninja and OpenSSL; the exact steps are in windows.yml.

Questions

Short answers; the README has the rest.

Where does the notch appear, and how do I open it?

At the top-centre of every monitor. Rest the mouse on the top edge (or drag a file there) and it slides out. When idle it shows a small clock; rest on it to open.

Where's the dock, and how do I keep apps in it?

On the bottom edge by default (Settings → Dock → Position). It hides until the pointer touches the edge, or switch on Always show. Press + to add apps or folders, right-click an app → Keep in Dock, or drag a running app among the pinned ones.

Why does a click on a dock app open a new window instead of switching?

Raising existing windows needs KDE Plasma (KWin) on Linux, or Windows. On other desktops the dock can only start apps.

How does the stretch reminder know I'm working?

It asks the system how long ago you last used the mouse or keyboard. Time with input counts as work; a few minutes away counts as a break. Nothing about what you type is read.

Windows says "Windows protected your PC". Is it safe?

The build isn't code-signed, so SmartScreen warns about any new download. Click More info → Run anyway. The installer is built by GitHub Actions from this repository's source.

Where are my files and settings?
  • Linux: ~/.local/share/notch (files) and ~/.config/notch (settings).
  • Windows: %LOCALAPPDATA%\notch.
