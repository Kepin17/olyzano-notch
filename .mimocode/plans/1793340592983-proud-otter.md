# Plan: Deadline radar + course category (Tasks untuk mahasiswa)

## Goal

Tasks menjadi “deadline radar”:
1. **Course/mata kuliah** per task (free-text + chips suggestion)
2. **H-3 urgency** — ≤3 jam tampil merah/kritis (visual saja, tanpa toast baru)
3. **Ticker 3 deadline** di capsule idle (multi-task, tetap 1 baris)

User memilih: free-text + chips, ticker 3, H-3 visual saja.

## Design

### 1. Course field (free-text + chips)

**Backend — `TasksModel.h` / `Tasks.cpp` / `Tasks.h`:**
- Tambah `QString course` di `Task` (`TasksModel.h:20-26`)
- `toJson`/`fromJson`: key `"course"` (lama tanpa key → empty, OK)
- `add(title, dueIso, course = {})` + `addQuick` parse opsional prefix `Course: tugas` (atau tanpa NLP course — v1 tanpa NLP course)
- `refresh()` tambah `course` ke item map
- Property baru `QVariantList courseSuggestions`: daftar unique course dari tasks (open+done), urut by count/frequency, max ~12 — untuk chips
- `setCourse(id, course)` untuk edit dari list (optional v1: cukup via dialog edit)

**UI — `TasksPage.qml`:**
- Dialog New/Edit: di bawah Deadline, baris chip **course suggestions** (Flow of PillButton/Text→click isi TextField) + TextField kecil “Course” (boleh kosong)
- List row: chip kecil `theme.accent`/surface di samping title kalau course non-kosong
- Filter course: baris chip filter di atas list: `All | CS101 | MATH…` (dari suggestions); klik filter = filter by course (combine dengan day filter yang sudah ada `:54`)

### 2. H-3 urgency (visual saja)

**`TasksModel.h`:**
- Constant `CriticalHours = 3`
- Enum/state: tambah `"critical"` di `dueState` — urutan: Overdue > Critical(due ≤ now+3h) > Soon(≤15m) > Later  
  *Catatan: Soon(15m) tetap di atas Critical untuk warn color; Critical = merah/warn, Soon = accent*
- Atau: state tetap + `critical` flag — **pilih state string `"critical"`** supaya QML satu switch

**Colors:**
- List bar (`TasksPage.qml:183-184`): critical → `theme.danger` (atau warn jika ada) — overdue tetap danger
- Calendar (`:116-122`): hari dengan task critical → merah (late sudah merah; critical boleh merah juga / oranye jika theme.warn ada)
- Capsule (`Main.qml:1652`): `critical` → danger

**Tidak ada** signal/toast baru (user: visual saja). `SoonMinutes=15` fire loop tidak diubah.

### 3. Ticker 3 deadline di capsule

**Tanpa C++ baru** — QML filter `tasks.list` yang sudah sorted (open+due-first):
```qml
readonly property var radar: tasks.list.filter(t => t.hasDue && !t.done).slice(0, 3)
```

**`Main.qml` idle content (`:1645-1655` area):**
- Jika `taskShown`: ganti single Text dengan **Row/Text ticker**:
  - Format per item: `CS101 Essay · 2h` (course prefix bila ada; remaining)
  - Gabung: `“CS101 Essay · 2h  ·  MATH Quiz · 5h  ·  PHYS Lab · besok”`
  - Elide di akhir; **satu baris**
  - Warna per segmen kompleks → v1: **satu Text**, warna = state dari **task pertama** (paling urgent) — cukup radar feel tanpa rewrite layout
- Alternatif v1.1: marquee/rotate antar 3 task tiap 4s — **skip dulu** (static join lebih simpel)
- Width: `Main.qml:1168` `infoShown` 390 → naikkan ke **460** saat task radar (3 item) — cek pillLook/capWidth
- Rotation vs prayer tetap (`:439-440`) — task slate = ticker 3, prayer slate = prayer

**Tap** (`:2800`): tetap buka Tasks page.

### 4. Tests — `tests/tst_core.cpp`

- `dueState`: now+2h → critical; now+15m → soon (bukan critical); now+4h → later; overdue → overdue
- JSON round-trip dengan course;fromJson tanpa course → empty
- `courseSuggestions` unique+count (jika logic pure di TasksModel)
- Regression existing task tests tetap hijau

| Risk | Mitigation |
