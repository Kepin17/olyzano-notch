1. Rename nav ActionBar **API → Dev** (id page `api` → `dev`).
2. Di dalam page Dev, **top Segmented: API | SSH | Database** — clean, modern, profesional (hanya `theme.*`).

### `secrets.json` (opt-in)

Hanya bila `savePassword: true`. Shape: `{ "ssh": { "<id>": "…" }, "db": { "<id>": "…" } }`. File 0600. Password **tidak** masuk connection JSON, **tidak** di argv, **tidak** di log.

## Controller API

### `SshManager` — context `sshManager`

- Props: `connections` (QVariantList), `busy`, `lastOutput` (string), `commandRunning`
- Invokables: `addConnection(map)→id`, `updateConnection(id, fields)`, `removeConnection(id)`, `duplicateConnection(id)`, `connectionById(id)`, `testConnection(id)`, `runCommand(id, cmd)`, `openTerminal(id)`
- Signals: `changed`, `busyChanged`, `outputChanged`, `commandFinished({ok, exitCode, output})`, `testFinished({ok, error, latencyMs})`, `statusMessage`
- Exec: QProcess argv `ssh [-i key] [-p port] -o BatchMode=yes -o StrictHostKeyChecking=accept-new user@host [cmd]`
- Password auth: prioritaskan key/agent; bila password tersimpan, spawn dengan env `SSH_ASKPASS` (helper `--askpass` di `main.cpp` baca secrets, print ke stdout saja) + `SSH_ASKPASS_REQUIRE=force`. Tanpa TTY injection.
- Open terminal: deteksi `xdg-terminal-exec` / `gnome-terminal` / `konsole` / `kitty` / `alacritty` / Windows `wt.exe`. Validasi host/user `[A-Za-z0-9._:@\[\]-]` sebelum argv.

### `DatabaseManager` — context `dbManager`

- Props: `drivers` (list string tersedia), `connections`, `connected`, `activeId`, `busy`, `lastError`, `lastResult` `{columns, rows, rowCount, error, durationMs, affected}`
- Invokables: `addConnection`, `updateConnection`, `removeConnection`, `connectionById`, `connectTo(id)`, `disconnect()`, `schemas()`, `tables(schema)`, `browseTable(schema, table, limit=50, offset=0)`, `execute(sql)`
- Signals: `changed`, `connectedChanged`, `busyChanged`, `resultReady(map)`, `statusMessage`
- Catalog: sqlite → `sqlite_master`; mysql/postgres → `information_schema.tables`. Identitas table di-quote per driver; nilai bound. Free SQL user memang intentional (phpMyAdmin-like).
- Koneksi QtSql: nama unik; tutup/ganti saat disconnect / ganti active.

# Lanjutan: notif (infoText) saat notch terbuka → sticky bottom

## Masalah

Banner konfirmasi `shell.infoText` (`Main.qml:2694–2713`) duduk **di alur ColumnLayout** `panel`, setelah semua loader halaman. Saat page Dev (API/SSH/DB) atau Settings tinggi, banner tidak menempel di dasar island — terasa “ngambang” / kurang enak dilihat. User minta pindah ke **bagian bawah** yang jelas saat notch open.

## Perubahan (satu file: `src/qml/Main.qml`)

1. **Keluarkan** blok `Rectangle` infoText (2694–2713) dan **Undo banner** (2715–2735) dari dalam `ColumnLayout { id: panel }`.
2. **Taruh sebagai overlay** di Item parent open-panel (`Main.qml:1850–1856`, yang `clip: true`), di **setelah** `panel` ColumnLayout, di-anchors:
   - `anchors.left/right` ≈ panel + margin 8
   - `anchors.bottom: parent.bottom` + `bottomMargin: 8`
   - `z: 10` agar di atas konten
3. Undo banner (shelf only) ikut di bottom yang sama, di **atas** infoText bila keduanya visible (spacing 6) — stack vertikal kecil di pojok bawah.
4. Sisanya tidak berubah: `infoTimer` 3500 ms, prefix ✓ / ⚠, `theme.infoBg`, `showToast` saat open tetap mengisi `infoText`.

## Layout hasil

Island open (Item clip)
