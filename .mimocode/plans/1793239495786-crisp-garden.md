# API Tester lokal (ala Postman) untuk Olyzano Notch

## Ringkasan permintaan

Fitur test API yang berjalan di dalam notch: HTTP client umum (kirim request ke URL mana pun, local + internet) **plus** preset untuk API yang dipakai app (relay share, GitHub, lrclib). UI = halaman baru di panel notch. Scope penuh: collections + folder, environments `{{var}}`, history, pretty JSON, script/test ala Postman, import/export.

## Arsitektur (mengikuti house style, tanpa dependensi baru)

| Bagian | File | Alasan |
|---|---|---|
| Logika murni (struct, JSON, substitusi `{{var}}`, history ring, Postman v2.1 map, pretty JSON) | `src/platform/ApiTesterModel.h` (header-only) | Pola `TasksModel.h`; bisa diuji dari `tst_core` tanpa ubah link |
| Controller QObject (QNAM, QSaveFile, QJSEngine, presets) | `src/platform/ApiTester.h` + `.cpp` | Pola `Tasks`/`Updates`; target `notch` saja supaya QJSEngine tidak masuk `notch_core` |
| Context property | `main.cpp` — `setContextProperty("apiTester", &apiTester)` (~baris 416) | |
| UI halaman | `src/qml/ApiPage.qml` | Checklist halaman baru (lihat di bawah) |

HTTP mengikuti pola kanonik `ShareController::memberCall` (`ShareController.cpp:490–523`) + `Updates` (redirect `NoLessSafeRedirectPolicy`, User-Agent, `setTransferTimeout` 30 dtk). GET/POST/PUT/PATCH (`sendCustomRequest`)/DELETE. Bukan server — klien saja. Tanpa multipart di v1 (form-urlencoded saja, untuk preset Discord).

## Skema data (disimpan di `GenericDataLocation/notch/apitester/`)

- `collections.json` — tree collection → folder/request; request punya `method,url,headers,query,bodyMode,body,auth,preScript,testScript`; flag `readonly` untuk preset.
- `environments.json` — daftar env + `activeId`; variabel `key/value/enabled`.
- `history.json` — ring buffer default 50 entri (method,url,status,durasi,headers,body terpotong 64 KiB, hasil test).
- `~/.config/notch/apitester.conf` (QSettings): `timeoutMs=30000`, `historyLimit=50`, `historyEnabled=true`, `prettyJson=true`, `followRedirects=true`.

Substitusi `{{key}}` hanya pada variabel enabled env aktif; key tak dikenal dibiarkan literal + warning badge.

## Scripting (QJSEngine, bukan sandbox Postman penuh)

- `preScript` / `testScript` per request; `QJSEngine` baru per fase; tanpa XMLHttpRequest/Qt/filesystem.
- API: `env.get/set/unset`, `console.log` → tab Scripts; fase test: `response.status/ok/time/headers/text()/json()`, `test(name,fn)`, `expect().toBe/toBeTruthy/toContain/toBeGreaterThan/…`.
- Urutan Send: substitute → preScript → substitute lagi → HTTP → testScript → history + `finished`.
- Guard waktu ~2 dtk (best effort); dokumentasikan “script pendek”.

## Import/export

- **Utama:** Postman Collection v2.1 (map `item[]`, `request.*`, `event[]` → pre/test script; terima `url.raw` maupun bentuk object) + Postman Environment.
- **Cadangan:** export native JSON (simpan `readonly`, script utuh).
- UX: file dialog (QtQuick.Dialogs) atau paste; toast jumlah item via `shell.infoText`.

## Langkah implementasi (berurutan, tiap phase compile + test hijau)

### Phase 0 — Skeleton
ApiPage placeholder + seluruh wiring navigation + `ApiTester` stub + main.cpp. Verifikasi: ActionBar “API” membuka halaman.

### Phase 1 — Model + unit test
`ApiTesterModel.h`: struct, toJson/fromJson, `substitute`, `historyPush`, `prettyJson`, mapper Postman v2.1. Slot test di `tst_core.cpp`: round-trip, substitusi, history ring, pretty JSON, import/export fixture, presets readonly.

### Phase 2 — Send + response
`ApiTester::send(QVariantMap draft)`: query/headers/auth/body/timeout/redirect; `lastResponse` (status, duration, bodyPretty, headers, error, tests). QML: bar method+URL+Send+pane response.

### Phase 3 — Persistence + collections CRUD
Load/save 3 file JSON (`QSaveFile` pola `Tasks.cpp:13,24–32`); invokables new/add/update/remove/rename/duplicate; load request ke builder; **presets read-only** Relay/GitHub/lrclib/Discord dibangun di C++ (merge saat file belum ada).

### Phase 4 — Environments
CRUD + picker aktif; substitusi ganda (sebelum/sesudah preScript); badge var unresolved.

### Phase 5 — History
Push setelah send (hormati `historyEnabled`/`historyLimit`); tab History; klik = restore ke builder; Clear history.

### Phase 6 — Body modes + polish
none/json/raw/form; pretty JSON; copy body; format ukuran/waktu.

### Phase 7 — Scripts QJSEngine
Runner pre/test + API di atas; hasil di tab Tests + scriptLog.

### Phase 8 — Import/export
Dialog file + `importPostmanCollection` / `exportPostmanCollection` (+ env); toast via `shell.infoText`.

### Phase 9 — Docs
- `README.md` bullet fitur
- `docs/user-guide.md` section baru (cara kirim request, env, preset relay, import Postman, catatan keamanan history bisa memuat token)
