# Refactor plan — Olyzano Notch

Hasil audit menyeluruh C++ (`src/platform|services|app`, 16 file >400 baris) dan QML (`src/qml`, 50 file / 17.8k baris). Tidak ada feature change — pure structural cleanup.

---

## Ringkasan temuan

**Duplikasi paling mahal** (harus diperbaiki N tempat kalau ada bug):
- `ownerOnlyPath()` copy-paste byte-for-byte di SshManager + DatabaseManager
- `secrets.json` R/W hampir identik (hanya key `"ssh"` vs `"db"`)
- `expandTilde` + connection CRUD + load/save JSON — Ssh & Db mirror total
- ~18 file punya boilerplate path `GenericConfigLocation + "/notch/<name>.conf"` + `QSettings(IniFormat)` manual
- Field.qml inline component duplikat di DbTab + SshTab; 34+ site restyle TextField background yang sama
- Confirm dialog chrome (Popup + dim:false + Overlay.modal + PillButton) diulang di 5+ file
- `say()` / status message timer diimplementasi 5× dengan strategi clear berbeda-beda

**File terlalu besar** (god objects):
- `NotchController.cpp` — 1775 baris, 8+ concern campur
- `Main.qml` — 3423 baris (geometry + toast + live activity + shelf + dialogs + page router)
- `AppDock.cpp` — 1229 baris, 3 platform #ifdef islands + embedded KWin JS
- `ApiTester.cpp` — 1155 baris, 5 subsystem
- `SettingsPage.qml` — 2585 baris, 9 section Loader tapi semuanya inline
- `ApiPage.qml` — 2232 baris
